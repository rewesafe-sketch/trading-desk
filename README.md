# Trading Desk

Static iPhone web app. GitHub Pages serves `main` at `/`.

https://rewesafe-sketch.github.io/trading-desk/#d=...

Use the `#d=` fragment Grok Bot sends you. An optional `#t=` fragment is saved in this browser only and is not part of this repo.

Home shows the paper balance from `state.json`. The desk polls every 15 seconds.
